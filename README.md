# Quiz Master

A modern, interactive quiz application built with TypeScript and Next.js. Take quizzes, track your progress, and challenge yourself!

## 📦 Installation

1. Clone the repository
```bash
git clone https://github.com/nishant-codess/quiz-master.git
```

2. Install dependencies
```bash
npm install
# or
yarn install
```

3. Set up environment variables
```bash
cp .env.example .env.local
```
Then update the environment variables with your Firebase configuration.

4. Start the development server
```bash
npm run dev
```
The application will be available at `http://localhost:9002`
